Este projeto é uma versão digital do clássico jogo de trunfo, utilizando cartas de baralho com atributos. Cada carta possui nome, imagem e atributos, e o objetivo é comparar atributos entre cartas para ganhar a rodada.
O jogo é feito em HTML, CSS e JavaScript, permitindo que as cartas sejam exibidas de forma interativa na tela.

🚀Sobre o Projeto

O Jogo de Trunfo de Cartas é uma aplicação web que simula o clássico jogo de cartas “Trunfo”, utilizando cartas de baralho como tema. Cada carta possui atributos únicos, permitindo que jogadores comparem suas cartas e decidam vencedores com base em critérios específicos.

O objetivo do projeto é:

Criar uma experiência de jogo simples e interativa no navegador.

Permitir que os jogadores aprendam lógica de comparação de atributos de forma divertida.

Demonstrar o uso de HTML, CSS e JavaScript para manipular arrays, objetos e DOM.

Como Funciona

O baralho é representado como um array de objetos, cada objeto representando uma carta com:

nome: nome da carta (ex: Ás de Copas)

imagem: URL da imagem da carta

atributos: conjunto de atributos como Força, Agilidade e Magia

Durante o jogo, o sistema sorteia cartas para o jogador e para o computador.

O jogador escolhe um atributo de sua carta e o compara com a carta do adversário.

O vencedor é definido pelo maior valor no atributo selecionado.

Diferenciais do Projeto

Uso de imagens públicas de cartas do baralho.

Estrutura modular em JavaScript, facilitando a adição de novas cartas e atributos.

Layout responsivo e simples, permitindo fácil visualização das cartas.

Projeto serve como base para jogos de cartas mais complexos, incluindo pontuação, rodadas e decks personalizados.

Tecnologias Utilizadas

HTML5: estrutura da página e elementos de interação.

CSS3: estilo das cartas e layout do jogo.

JavaScript (ES6): lógica do jogo, manipulação do DOM, comparação de atributos.
